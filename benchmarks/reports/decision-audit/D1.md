# D1 and reranker ensembling: exploratory DORIS replay

All methods rank the same 20 frozen candidates for each of 12 previously evaluated DORIS questions. Each document has the same 400-token bound. No new retrieval or relevance judging was performed.

D1 was requested as `~liquid/d1-ultra-latest` and resolved to `liquid/d1-ultra-20261015`. Historical Jev runs used `typesafe/jev-1.14`; the current Jev latest alias points to that same version. Historical Jev/Voyage timing was measured at a different time, so timing comparisons are observational.

| jev_single | 0.7598 | 5.258 | 0.000690 |
| jev_packed5 | 0.7581 | 1.194 | 0.000400 |

Ensembles combine ordered document ranks with equal-weight RRF (`k=60`), never average incompatible relevance scores. Ensemble results are free offline replays of member rankings; reported costs sum the member calls. Concurrent ensemble latency has not been measured.

The packed three-member ensemble gains 0.0168 nDCG@5 over Voyage, with paired bootstrap 95% interval [-0.0054, 0.0438]. All tested ensemble intervals include zero. These variants are exploratory on reused questions, with multiple comparisons and no fresh validation; the table does not establish a winning ensemble.

Packed D1 reduced observed median latency from 8.121s to 1.864s and reported input cost by about 26%. Its scores also changed slightly, as with packed Jev. Liquid documents per-question prompt billing; these measured savings are not evidence of a provider cache hit or a guarantee of shared-state token savings.

New D1 calls cost $0.009664116 in total. The conservative full-session estimate including the existing uncertainty allowance is $3.830296, below the $5 ceiling.
